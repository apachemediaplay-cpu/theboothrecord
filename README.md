# The Booth

"The Booth" (theboothrecord.com) is a confession web app and the customer-acquisition
front end for the brand **GUILTY**. Users confess, receive a deadpan one-line "verdict,"
and approved confessions appear on a public wall.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Postgres + Edge Functions)

## Getting started

Requires Node.js & npm.

```sh
# Install dependencies
npm i

# Start the dev server (http://localhost:8080)
npm run dev
```

## Environment variables

Configured in `.env` (see `src/integrations/supabase/client.ts`):

- `VITE_SUPABASE_URL` — Supabase project URL
- `VITE_SUPABASE_PUBLISHABLE_KEY` — Supabase publishable (anon) key
- `VITE_SUPABASE_PROJECT_ID` — Supabase project ref

## How it works

- **Confession flow:** landing → confidentiality → confess → receiving → verdict → public wall.
- **Verdicts** are generated by the `generate-verdict` Supabase Edge Function, which calls
  OpenAI server-side. The front end never calls OpenAI directly.
- **Storage:** confessions are written to the Supabase `confessions` table at the verdict
  stage (with venue `source` attribution and an optional email). New rows default to
  `status = 'pending'`; only `approved` rows appear on the public wall (enforced by RLS).

## Build & deploy

```sh
npm run build           # production build
npm run deploy:dev      # build + deploy to the dev Firebase project
npm run deploy:prod     # build + deploy to the prod Firebase project
```
